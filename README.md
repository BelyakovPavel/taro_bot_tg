# Таро-бот для Telegram

Telegram-бот для раскладов на картах Таро и нумерологии с ИИ-прогнозами на базе DeepSeek.

## Возможности

- 🃏 **Гадание на Таро** — расклад на три карты по заданному вопросу, с расшифровкой значений
- 🔮 **Нумерология** — расчёт и интерпретация по дате, времени и месту рождения
- 🤖 **ИИ-уточнение** — DeepSeek уточняет вопрос и дополняет ответ, если расклад получился неоднозначным
- 🚦 **Ограничение частоты запросов** — защита от спама и перегрузки (rate limiting)
- 🔒 **Приватность** — данные хранятся ограниченное время (TTL 48 часов) и автоматически удаляются
- 🧪 **Тестовый режим** — мгновенные ответы для проверки (в рабочем режиме ответ приходит через 1–2 часа)

## Технологии

| Компонент | Технология |
|---|---|
| Язык | Go 1.24 |
| Telegram API | [go-telegram/bot](https://github.com/go-telegram/bot) v1.23 |
| База данных | PostgreSQL (pgx v5) |
| ИИ-прогнозы | DeepSeek API |
| Конфигурация | godotenv (`.env`) |

## Быстрый старт

```bash
# 1. Скопируйте конфигурацию и заполните значения
cp .env.example .env

# 2. Соберите и запустите
go build -o bot ./cmd/bot
./bot
```

Таблицы в PostgreSQL создаются автоматически при старте (`CREATE TABLE IF NOT EXISTS`).

## Конфигурация (`.env`)

| Переменная | Обязательна | Описание |
|---|---|---|
| `BOT_TOKEN` | да | Токен бота от [@BotFather](https://t.me/BotFather) |
| `DATABASE_URL` | да | Строка подключения PostgreSQL, например `postgres://user:pass@host:5432/db?sslmode=require` |
| `AI_API_KEY` | нет | API-ключ DeepSeek (без него ИИ-функции отвечают ошибкой) |
| `PAYMENT_PROVIDER` | нет | Платёжный провайдер (yukassa, robokassa, …). Пока не реализован — бот работает в бесплатном режиме |
| `TEST_MODE` | нет | `1` — ответы приходят сразу, `0` — через случайные 1–2 часа |

## Структура проекта

```
cmd/bot/            точка входа
internal/config/    загрузка конфигурации из .env
internal/handlers/  обработчики команд (таро, нумерология, меню, …)
internal/ai/        клиент DeepSeek для прогнозов
internal/storage/   PostgreSQL-хранилище и схема БД
internal/models/    доменные модели (карты, запросы, пользователи)
internal/payment/   интеграция платежей (заглушка)
```
