# Политика обработки персональных данных Telegram-бота «Таро»

Настоящая политика описывает, какие персональные данные обрабатывает бот, зачем, как долго их хранит и какие права есть у пользователя. Используя бота, вы принимаете условия настоящей политики.

## 1. Какие данные собираются и зачем

| Данные | Источник | Назначение |
|---|---|---|
| Telegram ID, username, имя, фамилия | профиль Telegram при команде `/start` | идентификация пользователя и персонализация обращений |
| Номер телефона | кнопка «Поделиться номером» (только по инициативе пользователя) | не используется в текущей версии; собирается для будущих функций (уведомления, восстановление доступа) |
| Текст запроса | сообщение пользователя | расклад Таро и генерация прогноза |
| Дата, время и место рождения | сообщения пользователя | расчёт натальной карты (нумерология) |
| Результаты (прогнозы, натальные карты) | формируются ботом | доставка результата пользователю |

Бот не запрашивает пароли, пин-коды, документы, паспортные данные, платёжные реквизиты и иную информацию, не нужную для его работы.

## 2. Правовое основание и согласие

Обработка осуществляется на основании согласия пользователя, которое выражается началом использования бота (команда `/start`). Пользователь вправе отозвать согласие в любой момент, обратившись к администратору (см. раздел 7) или прекратив использование бота.

## 3. Передача третьим лицам

- Данные передаются сервису искусственного интеллекта **DeepSeek** (API `api.deepseek.com`) исключительно для генерации прогнозов и натальных карт. Это необходимо для работы функций бота. В запросе к ИИ передаются: текст запроса, дата/время/место рождения, карты расклада.
- Иным третьим лицам данные **не передаются и не продаются**. Telegram получает только то, что пользователь сам отправляет боту через свои клиенты.

## 4. Хранение данных и сроки

- Данные хранятся в базе данных PostgreSQL, размещённой на сервере оператора.
- **Запросы Таро** хранятся не более **48 часов** и затем удаляются автоматически фоновой задачей.
- **Профиль пользователя и нумерологические запросы** хранятся до момента удаления по запросу пользователя либо отзыва согласия.
- **4.1. Шифрование данных в покое (at-rest).** В настоящее время записи пользователей хранятся в базе данных в открытом виде, **без шифрования хранимых данных**. Это осознанное техническое ограничение текущей версии сервиса: база данных размещена локально и доступ к ней ограничен; шифрование at-rest планируется к внедрению при развёртывании на внешнем хостинге. Оператор не передаёт доступ к базе данных третьим лицам и уведомит пользователей об изменении данного порядка. Передача данных между компонентами и внешними API всегда выполняется по защищённому протоколу TLS/HTTPS.
- **4.2. Шифрование при передаче.** Все соединения бота с Telegram и с сервисом ИИ — по HTTPS (TLS). Для подключения к удалённой базе данных требуется `sslmode=require` (или `verify-full`).

## 5. Права пользователя

Пользователь вправе:
- получить сведения об обрабатываемых о нём данных;
- потребовать исправления неточных данных;
- потребовать удаления своих данных (команда `/privacy`, раздел 7).

## 6. Безопасность

- Доступ к функциям бота ограничен по частоте запросов (rate limiting) для защиты от спама и перегрузок.
- Входящий текст проверяется по длине; команды и пользовательский ввод не выполняются как код.
- Запросы к базе данных используют параметризованные SQL-запросы.
- Секреты (токен бота, ключ ИИ, строка подключения к БД) хранятся только в переменных окружения и не попадают в код и публичные репозитории.

## 7. Контакты

По вопросам, связанным с обработкой персональных данных, удалением данных или отзывом согласия, напишите администратору бота (команда `/privacy` в боте).
